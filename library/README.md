# The WAKILISHA Library

The Library is where WAKILISHA preserves its institutional memory.

This is not documentation.

This is where WAKILISHA stores the principles, Inquiries, Field Notes, letters, decisions, and working philosophy that guide the institution.

The Library exists so that future Inquirers do not only inherit what WAKILISHA built.

They inherit how WAKILISHA learned.

## Structure

- `constitutions/` contains the principles that guide the institution.
- `field-notes/` contains moments of learning, change, disagreement, and discovery.
- `inquiries/` contains long-running questions and research lines.
- `founder-letters/` contains occasional letters from JB and future institutional leaders.
- `things-we-laughed-about/` preserves the human moments that shaped the work.

## Rule

Do not casually edit the Library.

Amend it.

Annotate it.

Add to it.

If an old idea becomes wrong, do not erase it. Write the next Field Note.
