# The Question Framework

## First Law

WAKILISHA exists to answer meaningful questions about African culture.

Everything else is a consequence.

We do not publish because we need content.

We publish because a question deserves an answer.

## The Question Chooses The Medium

Never begin by asking:

Should this be an article?

Should this be a podcast?

Should this be a feature?

Ask:

> What is the best way to answer this question honestly?

Sometimes the answer is an article.

Sometimes a timeline.

Sometimes an artist page.

Sometimes a chart.

Sometimes a podcast.

Sometimes a film.

Sometimes a festival.

Sometimes software.

The medium serves the question.

## The WAKILISHA Loop

Question

Investigation

Relationships

Understanding

New Questions

The loop never ends.

Every answer should produce better questions.

Every question should deepen understanding.

## Four Invisible Questions

Every meaningful experience should answer four things.

1. What is this?
2. Why does it matter?
3. How is it connected?
4. Where can curiosity go next?

If we consistently answer these four questions, the product teaches itself.

## Final Principle

Most platforms organize content.

WAKILISHA organizes curiosity.
