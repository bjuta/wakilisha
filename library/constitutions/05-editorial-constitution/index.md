# The Editorial Constitution

## Publish because a question matters

WAKILISHA should not publish because the internet is hungry.

The internet is always hungry.

WAKILISHA should publish because a question matters, because evidence has been gathered, because a relationship needs explaining, because a memory is at risk of being flattened, or because a public conversation would become better with context.

This does not mean WAKILISHA must be slow. It means speed cannot be the deepest value.

Sometimes the right thing is a quick note that says exactly what is known. Sometimes the right thing is a long feature that takes time. Sometimes the right thing is to wait because the available answer would be thin, unfair, or false.

Editorial discipline is the ability to know the difference.

## What belongs

WAKILISHA publishes work that improves understanding.

That includes essays, artist notes, track context, chart analysis, guides, interviews, field notes, explainers, arguments, timelines, and carefully built pages that make relationships visible.

The form can change. The standard does not.

A WAKILISHA piece should give the reader at least one of these gifts.

A clearer question.

A better explanation.

A useful correction.

A relationship they had not noticed.

A memory preserved.

A pattern named.

An uncertainty made honest.

A path to keep going.

If a piece gives none of these, it does not yet belong.

## What does not belong

Rewritten press releases do not belong.

Thin celebrity updates do not belong.

Generic listicles do not belong.

SEO pages with no cultural answer do not belong.

Hype that could be copied from any entertainment site does not belong.

Padded biographies do not belong.

False authority does not belong.

Performative Africanness does not belong.

Coverage for coverage’s sake does not belong.

WAKILISHA is allowed to be timely. It is not allowed to be empty.

## Voice

The voice should feel human, specific, warm, and restrained.

Simple does not mean shallow.

Fun does not mean careless.

Serious does not mean boring.

African does not mean decorative.

The writing should be clear enough to be spoken out loud by someone who actually listens, reads, watches, and pays attention. If a sentence sounds like it was written to impress a grant committee, a startup demo, or a search engine before it was written for a person, it needs to change.

WAKILISHA can coin language, but it has to earn it. A coined term should help people see something. It should not hide thin thinking behind style.

The best WAKILISHA sentence should feel like a person making a precise observation, not a brand performing intelligence.

## Editorial restraint

Not everything needs to be explained to death.

Restraint is part of trust.

A short answer can be enough if the question is small. A long answer is necessary when the question demands depth. The length should follow the work, not ego.

WAKILISHA should avoid making every cultural moment feel monumental. Some things are minor and still worth noting. Some things are entertaining and do not need a thesis. Some things are important because they are local, quiet, or recurring, not because they can be inflated into a grand claim.

The reader should trust that when WAKILISHA says something matters, the claim has been earned.

## Evidence in editorial work

Every editorial claim should know what kind of claim it is.

A factual claim needs evidence.

An interpretation needs reasoning.

A memory needs attribution.

An inference needs humility.

An argument needs fairness.

A correction needs visibility.

A thin page needs honesty.

WAKILISHA should not write around missing evidence. It should name it.

There is a difference between saying this is true, this appears to be true, this is remembered by some people, this is claimed by the artist, and this is a pattern WAKILISHA is still investigating.

That difference is editorial integrity.

## Product implications

Editorial thinking should enter product surfaces.

Artist pages should not read like scraped biographies.

Track pages should not read like metadata tables.

Release pages should not read like storefront cards.

Chart pages should not read like trophy boards.

Search snippets should not only chase clicks. They should tell the reader why the result may help.

Empty states should not be cute when truth is needed. If WAKILISHA does not have public entries in a wing of the Library, it should say so plainly.

The product is full of editorial decisions. Every label, card, state, and route carries voice.

## Community implications

Editorial standards should shape community design.

A comment system should not only ask people to react. It should invite context, memory, correction, and disagreement that can improve the Inquiry.

Moderation should not mean removing discomfort. Some disagreement is part of understanding.

But WAKILISHA should reject harassment, lazy contempt, identity mockery, misinformation, and empty provocation. A thread can be lively without becoming careless.

The editorial standard for community is not agreement. It is contribution.

## AI implications

AI can help draft, but it should not set the editorial bar.

A machine can produce a fluent paragraph faster than a human can think through a claim. That speed is dangerous if WAKILISHA confuses fluency with judgment.

AI-assisted editorial work must still pass the same tests.

What question does it answer?

What evidence supports it?

What uncertainty does it name?

What relationship does it reveal?

Does it sound like WAKILISHA, or like a culture product trying to sound important?

If the answer fails, the draft fails.

## Decision tests

What will the reader understand after this?

Why should WAKILISHA carry this, instead of anyone else?

Is the claim supported, interpreted, remembered, or inferred?

Have we made that clear?

Is the language plain enough to be useful?

Does the piece open a better next question?

Are we publishing because the question matters, or because the feed needs feeding?

## Failure modes

WAKILISHA is drifting when it publishes more and says less.

It is drifting when every trend becomes a story.

It is drifting when voice becomes clever before it becomes clear.

It is drifting when editorial pages are written for algorithms before people.

It is drifting when AI drafts arrive without evidence.

It is drifting when public copy starts sounding like product marketing.

It is drifting when the reader cannot tell what WAKILISHA believes and what it merely repeats.

## Closing note

Editorial work is not decoration around the product.

It is one of the ways WAKILISHA thinks in public.

The institution should publish like it expects to be read now, questioned later, and remembered by people who care whether it told the truth.
