# The AI Constitution

## AI can assist inquiry. It cannot replace inquiry

AI can assist inquiry.

It cannot replace inquiry.

This is the central rule.

WAKILISHA can use AI. It should use AI where the tool genuinely helps organize memory, compare evidence, draft possibilities, find patterns, suggest questions, and reduce repetitive work.

But WAKILISHA must never let AI counterfeit knowing.

The danger is not that AI will sound bad. The danger is that it will sound good while knowing too little.

A fluent paragraph can hide an empty evidence base. A confident summary can flatten uncertainty. A generated biography can make every artist sound important in the same way. A suggested relationship can look plausible and still be culturally false.

AI is useful. It is also dangerous in exactly the places where WAKILISHA must be most careful.

## What AI may do

AI may help WAKILISHA organize material.

It may summarize known facts.

It may draft first-pass descriptions for human review.

It may suggest possible questions.

It may find repeated collaborators, themes, dates, and relationships.

It may help cluster comments into contribution types.

It may help identify missing fields and thin pages.

It may help compare old and new versions of a principle.

It may help future builders read the Library and understand what rules apply.

It may help generate cautious copy when the evidence boundary is clear.

These are good uses because they support human inquiry.

## What AI must not do

AI must not invent facts.

It must not invent credits.

It must not invent cultural importance.

It must not turn platform metadata into biography.

It must not imply WAKILISHA has evidence it does not have.

It must not write around missing data.

It must not make every artist, song, release, or scene sound equally important.

It must not erase uncertainty to improve rhythm.

It must not replace editorial judgment.

It must not moderate cultural language without human review where stakes are high.

It must not speak in a voice that makes WAKILISHA sound generic.

## Evidence boundary

Every AI output should know its evidence boundary.

Known.

Inferred.

Unverified.

Missing.

Needs human review.

These states should shape the output. If the system knows little, the output should be modest. If the system has strong evidence, the output can be clearer. If the system is guessing, the output should not ship as fact.

The evidence boundary is more important than the style of the paragraph.

A beautiful lie is still a lie.

A plain, honest note is better.

## Voice boundary

AI must respect WAKILISHA voice.

No startup language.

No generic culture branding.

No grand claims without evidence.

No decorative Africanness.

No false intimacy.

No cheerful filler where truth is needed.

No em dashes.

No cleverness that makes the sentence harder to understand.

The voice should sound like a person at WAKILISHA who pays attention, speaks clearly, and respects the work.

If AI cannot produce that voice, the output needs editing or rejection.

## Product implications

AI should be wired into the product through the Question Spine.

When generating a summary, it should know the primary question.

When suggesting related paths, it should know the relationship type.

When drafting an artist note, it should know which facts are confirmed and which are missing.

When summarizing a comment thread, it should distinguish correction, memory, question, and disagreement.

When assisting search, it should help users find the path that matches their question.

When supporting admin review, it should make uncertainty easier to see.

AI should make the product more truthful, not only more efficient.

## Editorial implications

AI drafts should enter editorial work as drafts, not decisions.

A human should review public-facing AI copy for evidence, voice, tone, claim discipline, and cultural fairness.

Editors should be able to see what the AI used, what it inferred, and what it could not know.

If that trail is unavailable, the output should be treated with extra caution.

No one should publish AI text only because it sounds ready.

Sounding ready is not the same as being ready.

## Community implications

AI can help community work, but it must be humble.

It can flag possible abuse.

It can group repeated corrections.

It can surface useful comments.

It can summarize thread themes for moderators.

It can identify questions people keep asking.

But it should not erase the texture of community memory. Local language, joke, irony, grief, pride, and disagreement often carry context that a model may miss.

High-stakes moderation needs human judgment.

## Institutional memory implications

AI should help WAKILISHA remember its own rules.

A future AI assistant should be able to read the Library and warn when a proposed feature violates the constitution.

It should be able to say: this page answers a topic, not a question.

It should be able to say: this copy sounds padded because the data is thin.

It should be able to say: this related module shows proximity, not relationship.

It should be able to say: this draft has evidence claims that need checking.

AI should become a guardian of the institution’s memory, not a tool that helps the institution forget.

## Decision tests

What question is AI helping answer?

What evidence does the AI have?

What evidence is missing?

Is the output known, inferred, or speculative?

Does a human need to review it before publication?

Does the output sound like WAKILISHA?

Does it make uncertainty visible?

Would we be comfortable explaining how this output was made?

## Failure modes

WAKILISHA is drifting when AI copy sounds fuller than the evidence.

It is drifting when AI turns thin pages into generic praise.

It is drifting when AI suggests relationships without labels or support.

It is drifting when human review becomes a rubber stamp.

It is drifting when AI moderation misunderstands cultural language.

It is drifting when AI is used to publish faster while understanding gets weaker.

## Closing note

AI should help WAKILISHA ask better questions, remember more carefully, and reduce the weight of repetitive work.

It should never be allowed to make the institution pretend.

The rule is simple.

Assist inquiry. Do not replace it.
