## Media import boundary

This audit is for route preservation, not wholesale image importing.

Only old WordPress upload media under /wp-content/uploads/ should be mirrored or rewritten to the Lightsail media origin.

Do not import artist images or other provider-hosted images that already resolve from Spotify CDN, Apple, YouTube, or other provider CDNs unless there is a separate legal/product reason to cache them.

Artist images should continue to use provider CDN URLs where available.

## Cutover rule

Every preserve_or_map route needs one of these before wakilisha.africa points at React:

- Native React route
- React redirect
- Static legacy page
- Explicit intentional 404
