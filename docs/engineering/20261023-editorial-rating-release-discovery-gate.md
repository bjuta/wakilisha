# WAKILISHA editorial ratings and Registry Insert gate

Authority: owner-supplied MIZIZI WAKILISHA Brand Workbook (3), Chapter 24, 23 October 2026.

## Rating contract

One locally rendered SVG, structured and movable TipTap rating atom for shared rich-text workspaces. Legal values 1.0 to 5.0 in half steps; stars filled and in text colour, half values clipped. An inline rating stays in text; block goes between paragraphs; breakdown carries up to eight named scores; the verdict appears only once and is moved to the end. Rating values are stored as numeric document attributes, not Unicode emoji. A published Article only emits schema.org Review if the author explicitly names the reviewed work for its verdict. No invented review target, no reader-average conflation.

Insert menu, slash command and shared toolbar own rating insertion. Selected ratings can be edited. Typed prose remains unchanged until the author presses Convert Rating. Arrow keys step by 0.5; Home/End and keys 1–5 are supported. The same CSS is globally loaded for public and Studio pages. A dedicated complete workbook acceptance remains required for smaller cards, search indexing, Feed and other admin editors; do not assert those surfaces are already wired.
