MIZIZI design system · v3 · derived from the WAKILISHA workbookMIZIZIRoots, applied. Thirteen real screens from Product v4, each specified to the pixel, with the rules MIZIZI inherits and the few it adds.Mother system: brand workbook →
01Light-first, dark for publicHeadquarters, Field and Contributions run on paper #FCFCFB. Record and any artist-facing hero go dark and visual-first like WAKILISHA.
02Inherited, unchangedFigtree + IBM Plex Mono, 4px spacing, radii 8/12/16/24/999, motion, one menu, no chrome, floating controls, 44px targets.
03The only chromaFive standings. Established is #85C441 (text #4E7425, tint #EDF5E3). No other green, no decorative colour in Headquarters.
04Poster type, scopedUppercase poster titles only on Record and public heroes. Headquarters titles are 34/700 sentence case; people’s names never in caps.
05Mono means exactIDs, grades, revisions, hashes, timestamps, method versions. Never mono for prose.
06Every claim opensAny standing, number or credit opens to sources, grade and decision. No dead labels.
